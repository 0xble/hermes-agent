# Request usage ledger

- **Patch identity:** `request-usage-ledger`
- **Contract tests:** `tests/hermes_cli/test_request_usage_ledger.py`
- **Behavior:** Every physical provider request, including auxiliary calls, retries and fallbacks, appends exactly one size- and route-only row: session, source, role or task label, cron job, requested and resolved provider and model, fallback index, failure class, input, cache-read, cache-write and output tokens, and system-prompt tier sizes. `system_prompt_tier_sizes` is the complete `stable`/`context`/`volatile` character-size mapping when available and consistent with the cached prompt, or `{"total": N}` for a restored/reassigned prompt whose tier boundaries cannot be trusted. Attended-model switch-backs add their own row (from and to model, idle-gap bucket). Rows never contain prompts, messages, tool output or secrets, the key set is fixed, and incognito sessions write nothing. Writes are queued to a background thread, never block or raise in the request path, and count failures; the process-exit handler gives the queue a bounded two-second drain. Auxiliary rows use the bound session source and cron job identity rather than raw provider payload labels. Provider errors recovered before classification still emit one error row. Files are daily JSONL under `HERMES_HOME`, mode 0600, pruned past the retention window. `hermes usage` reads and filters them.
- **Scope limits:** The ledger is always on, with no config switch, because rows carry only sizes, routes and ids, never content, and incognito sessions write nothing. Brian approved it on 2026-11-15 as size- and route-only telemetry. Auxiliary rows record the route that served the call (requested equals resolved, fallback index 0, no prompt tiers), because the auxiliary client does not expose its internal fallback chain. A content-filter refusal records an error row without token counts. A forked child process opens its own ledger, because the parent's writer thread does not survive the fork.
- **Surfaces:** `hermes_cli/observability/request_usage_ledger.py`, `hermes_cli/subcommands/usage.py`, `agent/turn_usage.py`, `agent/api_request_hooks.py`, `agent/auxiliary_hooks.py`, `agent/system_prompt.py`, and `gateway/run_turn_runner.py`.
- **Retirement:** Remove this patch when upstream records per-request route and token usage with the same content-free guarantee.
- **Rollback:** Revert the commits carrying `Fork-Patch: request-usage-ledger`.

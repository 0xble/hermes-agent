# Goals and genuine-user turn authority

This responsibility covers goal state, user-origin projections, synthetic turns, reasoning controls and canonical final answers. The [root contract](../MAINTENANCE.md)
requires it on every run and owns shared adoption/publication policy.

## Coupled current adaptations

control revisions use the existing SQLite metadata compare-and-set operation
so concurrent processes cannot publish the same revision and preserve older
turn authority. This fixes revision allocation, not serialization of the whole
goal activation transaction. Focused regressions cover this boundary.
